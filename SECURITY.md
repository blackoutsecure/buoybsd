# Security policy

## Supported versions

BuoyBSD is an experimental replay prototype without a supported
production release or certified native FreeBSD collector.
Do not rely on it as a security boundary.

## Reporting a vulnerability

Do not disclose vulnerabilities, sensitive telemetry, credentials, or
customer information in a public issue.

Use
[GitHub private vulnerability reporting](https://github.com/blackoutsecure/int-buoybsd/security/advisories/new)
when available. If private reporting is unavailable, use the
organization's [security contact guidance](https://github.com/blackoutsecure/.github/blob/main/SECURITY.md).

Provide the affected revision, platform, a minimal sanitized
reproduction, expected/observed behavior, and impact. Do not attach
live process environments, secrets, full host audit trails, or unsafe
proof-of-concept payloads.

The project does not promise a response SLA. See
[the security model](docs/security-model.md) for current boundaries
and deployment limitations.
