# Dependency notices

These snapshots are generated by `make notices` (or
`cargo run --locked --features tooling --bin buoy-dev -- notices`) and
checked by `make license`:

- `dependencies/`: complete packaged license/notice files for the
  locked, target-inclusive normal dependency closure.
- `rust/`: the selected Rust toolchain's `COPYRIGHT-library.html`
  and referenced license texts, copied from its `rust-docs` component.
- `runtime-index.json`: package versions, registry sources, SPDX
  expressions, and SHA-256 digests for the snapshots.
- `upstream-sources.json`: reviewed complete upstream text and pinned
  commit/digest when an archive omits its license file (currently pbjson).

Do not edit these notices by hand or remove upstream copyright text.
Ship this directory with LICENSE and NOTICE in any binary distribution.
Feature-gated generator tooling and build/development-only dependencies
are not described as sensor runtime code. Target OpenSSL/GNU-system
libraries may require additional notices before binary distribution.
Snapshots establish consistency, not legal clearance.
See [provenance](../docs/provenance.md).
